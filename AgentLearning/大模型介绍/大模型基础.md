困境：传统规则说不完，传统 NLP 并不理解语义仅仅是算概率算词频

# 大模型的出现让机器真正“理解”语言

大模型（Large Language Model，LLM）的出现彻底改变了这个局面。

大模型的训练方式可以简单理解为：让机器阅读互联网上海量的文本数据——书籍、网页、论坛、代码、新闻、百科、论文……从中学习语言的规律和知识。它不是靠人写规则，而是靠"读"了足够多的文本之后，自己"悟"出了语言是怎么运作的。

# 大语言模型定义

大语言模型是一种基于深度学习的人工智能模型，通过在海量文本数据上进行训练，学习语言的统计规律和知识表示，从而具备理解和生成自然语言的能力。

这个定义有几个关键词：

* 深度学习：大模型的技术基础是深度神经网络，通常采用 Transformer 架构
* 海量文本数据：训练数据量达到 TB 甚至 PB 级别
* 统计规律：模型学习的是词语之间的概率关系，而不是硬编码的规则
* 理解和生成：既能读懂人类的语言，也能产出人类可读的文本

# 何为大模型

## 参数量巨大

参数即为神经网路中的权重，每个参数都是具体的数字，记录了模型通过学习到的所有知识，可以理解为大脑里的“神经连接”。神经元之间触碰连接形成了思维和智能

一般来说，参数量越大，模型的能力越强。但这不是线性关系，而是存在一些"涌现"效应。

什么是涌现？就是当模型规模突破某个临界点时，突然具备了之前没有的能力。

参数并非越大越好：

* 推理速度变慢，计算量大
* 成本高
* 过于“聪明”答非所问*

## 训练数据量大

大模型的数据量就是它处理问题的能力

*目前存在问题* ：高质量的、适合训练的数据越来越少

* 合成数据：让大模型自己生成数据，然后用这种数据来训练更强大的模型
* 更高效的训练方法 ：用更少的数据达到同样的效果：课程学习和知识蒸馏的技术
* 多模态数据：不仅使用文本，还可以使用图像，声音，视频

## 算力需求巨大

* API 服务：直接调用 API 就能使用顶级模型的能力
* 开源模型
* 模型量化：通过量化，把模型的体积压小
* 推理优化：各种推理框架大幅降低了大模型的硬件要求
